# CoAssure

**Voice-first safety assistant for field workers and teams.**

CoAssure makes it easy to think through hazards, fill out safety documents, run toolbox talks, and report what's happening on site — using conversation instead of clipboards. It works alongside existing safety platforms (SafetyCulture, Procore, HammerTech) and becomes the primary system on smaller sites that don't have one.

## Core Concept

Workers on changing job sites, small-to-medium projects, and field service roles face the same safety compliance burden as Tier 1 projects — but without the safety infrastructure to support them. CoAssure fills that gap with five entry points:

1. **Pre-Start Talk-Through** — Solo or small crew talks through the job; AI challenges with context-aware questions
2. **Facilitated Toolbox Talk** — AI assists the supervisor or runs the briefing for crews without one
3. **Form Assistant** — Scan a QR code or photograph any form; get walked through it conversationally
4. **Easy Reporting** — Near-miss, hazard, good catch, observation — tap, talk, snap, done
5. **Post-Job Reflection** — Capture what happened and what the next person should know

Every interaction pulls in weather, location, organisational standards, crowd-sourced hazard reports, and industry alerts. The output fits into whatever system the organisation already uses — or becomes the system on sites that don't have one.
